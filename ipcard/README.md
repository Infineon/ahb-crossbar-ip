# AHB Crossbar IP Card

This directory contains metadata and distribution collateral for the AHB-Lite
crossbar IP.

## Files

- [`ahb-crossbar-ipcard.json`](ahb-crossbar-ipcard.json) - Machine-readable IP
  metadata.
- [`ahb-crossbar-ipcard.pdf`](ahb-crossbar-ipcard.pdf) - Human-readable IP
  card.

## IP summary

The IP is written in SystemVerilog, targets FPGA and ASIC implementations, and
uses AHB-Lite interfaces. It is distributed with the [`Bender.yml`](../Bender.yml)
manifest and includes formal verification collateral.

## Usage

Use the JSON file for IP inventory or automation workflows. Refer to the PDF
for the full IP-card presentation and to [`../README.md`](../README.md) for
RTL integration details.
